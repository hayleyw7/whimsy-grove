# Spooky Grove

An illustrated scene editor hosted privately on OpenAI Sites.

## Account persistence
The existing Sites dispatcher provides the authenticated user ID. Built-in ChatGPT sign-in is used. No Google OAuth or app-owned login credentials are used. The private Site access boundary is unchanged. API requests without this identity are rejected.

D1 stores each account’s current draft, scene JSON, Album/History metadata, account-scoped favorite item choices, and transactional naming counters. History names display as Auto Save 1, Auto Save 2, and so on. New and renamed Album names allow up to 15 grapheme clusters, with duplicate suffixes included in the limit. Typing, paste, selection replacement, and committed IME text are limited in the input, and the same Unicode-aware limit is enforced on the server. Existing longer names remain unchanged. Manual Album names are entered before saving, preserve the user’s capitalization, and receive a numbered suffix when duplicated. Leaving the name empty uses the next Grove number. Name allocation and insertion run in the same D1 transaction. Album titles can be renamed independently of History titles. Creation timestamps remain separate metadata and display on one row, with the time on the right and no seconds. Titles use one line with a full-name tooltip, and metadata spacing is tight and consistent across equal-height cards. Previews preserve the full image without cropping. Ellipsis actions have a small 22-pixel face over the image corner within a 44-pixel touch target, and the compact Album sort chooser is next to the History tab. Counter increments and record inserts are a single D1 transaction, so simultaneous saves cannot reuse a number, failed saves do not consume one, and deletion never resets the sequence. Favorites is a filter, not a ninth category. R2 stores thumbnails. Every list, read, thumbnail, and update is filtered by the authenticated owner. The frontend never supplies the owner ID. Mutating requests require a matching Origin and an application header.

Every confirmed New, Randomize, or Open first saves and verifies the existing scene in History. Editing interactions are locked during this operation. If saving fails, the current scene remains unchanged. Album is saved manually, and History records can also appear in Album. Creations retain editable scene data, not just pictures. Individual saved records can be permanently deleted only after a themed confirmation names the target and affected collections. Server-side deletion checks owner, collection membership, confirmation, and the current title. Removing a record deletes it from both Album and History when present in both, and removes its thumbnail. A thumbnail cleanup failure is reported without misrepresenting the outcome.

The editor supports anonymous play when hosted with public access, but this deployment remains private. Save, Album, History, synced Favorites, New, and Randomize prompt anonymous visitors to sign in. Download and Share work without an app account. A pending login draft stays in tab-scoped session storage and is restored before editing is enabled after returning from sign-in. Drafts are not cloud saves. Loading operations show a spinner and a specific status, including loading favorite oddities, saving to Album, loading worlds, and editing saved creations.

Blank is a flat, subtly tinted near-white world. Void remains near-black. Light-mode oddity tiles share a flat surface, and the title has no shadow. Scrollable panels use persistent themed overflow tracks with keyboard and pointer controls, including on systems that hide native scrollbars. No track appears without overflow. Interface labels and catalogue names use Title Case, while user-entered creation names remain unchanged.

Current creations autosave to an owner-scoped D1 row after edits. Draft writes carry the opaque account scope returned by the server, so a changed sign-in cannot write the previous account’s scene into another account. A pending device backup protects edits during network interruption and is read only after the account is identified. Requests are serialized, retried edits are idempotent, and simultaneous first visits cannot replace an existing draft with a new random world. Guest drafts stay on the current device. A failure to read a cloud draft never silently starts a new random world. Album and History remain separate from the working draft.

## Source and build
- `public/` contains the client and bundled original artwork.
- `worker/index.js` contains the authenticated API and static asset fallback.
- `db/schema.ts` and the immutable `drizzle/` migrations define storage.
- `npm run build` produces Cloudflare Worker output and client assets.

A server is required for Album and History. The artwork and editor remain portable, but a future itch.io edition needs an explicit persistence plan rather than pretending account saves are device-local.

Downloads and native shared images use timestamped filenames with a random suffix. Oddity rerenders preserve the native-scrollbar suppression class, leaving one persistent themed overflow indicator.

Transient feedback lasts 2.1 seconds and uses a translucent, readable surface. Progress suppresses transient toasts, and only the latest queued toast appears after progress ends. Routine working-draft saves are silent, and opening saved work uses Loading grove during its protected load. Progress and confirmation dialogs remain visible until their operation or user choice completes. Persistent sync errors remain inline. Bottom action buttons have no raised shadow.

New selectable worlds include Greenhouse, Tide Pools, Ruins, Attic, Crystal Cavern, Frozen Lake, and Rooftop. Their artwork preserves placement space and omits baked-in celestial discs. All use the same palette and export renderer, and are accepted by account scene storage.

The Add shortcut and Search... placeholder reduce repeated Oddities labels. Counts show items or their current category. Loading keeps the current canvas bitmap visible and desaturated with a clear progress pill. Backgrounds and restored creations are rendered offscreen before the scene changes. Failed asset preparation preserves the current state and image, and History is still saved before replacing a creation.

Audio uses original procedural Web Audio buffers with three ambient loops: Gentle, Haunted, and Cosmic. Music and sound effects are off by default. Track, music volume, sound-effect preference, and master mute are device preferences. Remembered enabled audio still requires a trusted user action before starting. Master mute preserves individual settings. Music crossfades with bounded voices, effects are throttled and limited, hidden tabs suspend, and page exit closes the context and frees buffers.

New default Album names use the approved short background prefix plus Grove and the account sequence, such as Haunt Grove 999. After 999, automatic names use Grove 1000 to avoid clipped words. Existing titles are preserved. Blank uses a discernible pale lavender field in Original, shared by the canvas and image export.

Clicking or tapping outside a popup closes it. Backdrop dismissal cancels confirmation and naming dialogs, while ongoing work is not canceled. Any pointer press dismisses a visible transient toast without consuming the underlying interaction. Escape and closing dialogs restore focus. Gallery action menus fit their text, and switching collections keeps the existing cards and container height during loading.
