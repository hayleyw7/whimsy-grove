Help

Start a grove

Pick an idea to start in its biome, or pick Free Create for a random biome. More Ideas shows two more prompts. Select Start Creating when you’re ready, or Go Back to keep browsing.

Make it yours

Change the biome, weather, or colors above the canvas. On mobile, tap + to open Oddities. Tap an oddity to add it, or tap its heart to save it as a favorite. Select a placed oddity to move, resize, rotate, or remove it.

Keep your grove

Add to Album saves an editable copy. Starting over keeps the previous grove in History. Saves stay in this browser. Use Album’s Import / Export menu to move editable backups, or Download for a PNG or GIF.

Adjust settings

Use Menu to change the theme, music, sound effects, or animations.
